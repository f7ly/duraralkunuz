# درر الكنوز العربية — قالب سلة

قالب عربي RTL لمنصة سلة مبني على بنية Twilight. الهوية والتصميم أصليان، ولا يستخدمان شعار أو صور أو نصوص متجر زايروس.

## التطوير والمعاينة على سلة

يتطلب القالب Node.js بالإصدار `22.18.0` أو أحدث، وحساب مطوّر لدى شركاء سلة وتهيئة Salla CLI:

```sh
npm install
npm run production
salla theme preview
```

لإنشاء قالب قابل للاستيراد، اربط المجلد بمستودع GitHub في بوابة شركاء سلة، ثم اختر استيراد القالب. حدّث حقلي `repository` و`author_email` في `twilight.json` إلى بيانات حسابك قبل النشر. يلزم أيضاً توصيل النطاقات الفعلية للفئات وصفحات السياسات من لوحة سلة، وإضافة مكونات المنتجات والصور من معاينة القالب؛ قسم المنتجات في الصفحة الرئيسية يستخدم مكونات Twilight التي يضبطها التاجر.

## الصور

تستخدم المعاينة صوراً تحريرية من Unsplash عبر روابط خارجية. استبدلها بصور منتجاتك المرفوعة إلى سلة قبل النشر، وأضف صوراً بديلة محلية عند الحاجة.
